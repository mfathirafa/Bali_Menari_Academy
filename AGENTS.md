# Bali Menari Academy

Website satu halaman untuk Bali Menari Academy.

## Perintah untuk Agen AI

- Bahasa proyek: **TypeScript + Next.js App Router**
- Styling: **Tailwind CSS v4** (konfigurasi di `app/globals.css`, bukan `tailwind.config.ts`)
- Semua konten ada di `app/page.tsx` (single page app)
- Foto galeri: `public/images/gallery/frame-*.webp`
- Gambar dioptimasi dengan `next/image`
